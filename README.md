# Microscopy 3D Printing with Python

This project contains 3D-printable designs related to microscopy, generated using Python-based CAD libraries like [CadQuery](https://cadquery.readthedocs.io/) and [build123d](https://build123d.readthedocs.io/). The models are intended for educational, research, or DIY microscopy setups.

## 🛠 Features

- Custom microscope parts (e.g. holders, adapters, stage components)
- Parametric designs for easy modification
- Exportable to STL for direct 3D printing
- Built with Python scripts using:
  -  CadQuery
  -  build123d
